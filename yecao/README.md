# 《野草》題辭 — 代碼生成短片

約 3 分 28 秒。畫面與聲音全部由程式生成：Python 逐影格渲染（pycairo 向量 + numpy 粒子／噪聲場），聲音以 numpy／scipy 合成，ffmpeg 合成影音。不使用任何外部影像或音檔，只用 Noto Serif TC／Noto Sans TC 字體。固定隨機種子，每次輸出一致。

## 目錄

| 路徑 | 內容 |
|---|---|
| `config/timeline.toml` | 時間軸、關鍵時間點、脈搏（BPM 與錨點）、字幕全文、配色、年份／名字層、口號網格文字 |
| `config/edit.toml` | 剪輯：每一個鏡頭的起點、取景（放大倍數與中心）、推拉搖移、黑／白／閃回、無聲，以及自動生成的鏡頭串 |
| `STORYBOARD.md` | 時間線與逐鏡分鏡，由 `make_storyboard.py` 依兩份設定產生 |
| `ycf/edit.py` | 剪輯層：讀 edit.toml，依場景資料生成蒙太奇（每一下踐踏切一個近景、作證時每拍一切、火速時夾進閃回） |
| `fonts/` | Noto Serif TC（Light／Regular）、Noto Sans TC Medium，由 `tools/fetch_fonts.sh` 產生 |
| `ycf/fonts.py` | 由字形輪廓取出多邊形，字幕、字草、印版、輪廓共用 |
| `ycf/subtitles.py` | 一字一字浮現、銘文式刻出、直排落款、「手的痕跡」 |
| `ycf/scene_opening.py` | 第 1–3 段：微粒與裂縫、葉脈死與生、泥 |
| `ycf/scene_field.py` | 第 4–10 段：喬木崩成筆畫、字草物理、口號印版踐踏、刪刈、網格、地火、灰燼、作證 |
| `ycf/scene_end.py` | 第 11–12 段：火速循環、直排全詩被風吹散、土色 |
| `ycf/atmos.py` | 天空雲霧、土壤剖面（地層、碎石、埋著的殘筆）、空氣中的塵、光束 |
| `ycf/leaf.py`、`ycf/tree.py`、`ycf/clump.py` | 葉脈網路、L-system 喬木、「一叢野草」 |

| `render.py` | 渲染入口 |

## 剪輯

場景是連續演算的（字草的擺動、灰燼的運動都一直在模擬），剪輯層決定每一格「從哪裡看」。
每個場景都能用虛擬攝影機取景：向量圖層（字、葉脈、喬木、輪廓）透過 cairo 矩陣放大，點（微粒、灰燼、塵）變換座標，
所以特寫仍然銳利；只有平滑的圖層（天空、熔岩、光束）是裁切放大。

鏡頭種類：場景（可推拉搖移、可跟拍）、黑、白、閃回（先前某一刻的全景，渲染前先拍好存在 `out/cache/`）。
`[[burst]]` 依場景資料生成鏡頭串：

| type | 段落 | 做法 |
|---|---|---|
| `alternate` | 2 | 左右兩個取景交替，鏡頭由 0.6 秒縮到 0.12 秒 |
| `names` | 4 | 地底每一個名字閃現時，切一個大特寫 |
| `stomps` | 4 | 每一下踐踏切到落點的近景，每一刀切到會被切到的那一株；1:10 之後踐踏落地那一格閃白 |
| `grid` | 6 | 口號網格與被排進格子的野草，每一拍交替 |
| `witness` | 10 | 分界線每一拍重切，鏡頭也每一拍一切；每一對輪廓出現時，在兩側之間切 |
| `cycle` | 11 | 每一圈換一個取景；越轉越快時夾進閃回，最後兩秒每一兩格一張先前的畫面 |

聲音跟著剪輯：黑畫面若標了 `mute` 就完全無聲；蒙太奇的剪接點有一聲極短的切音；每一次閃回都把那一刻的聲音碎片帶過來。

## 聲音

聲音不另寫時間表：`ycf/sound.py` 直接建立場景物件，讀出畫面裡的事件來發聲，所以兩者不可能錯開。例如：

- 每一條葉脈熄滅的時刻與位置 → 一聲極輕的玻璃碎響，聲像在左
- 每一株字草冒出的時刻與位置 → 一筆刷過的聲音
- 畫面上陣風的強度與位置 → 風聲的大小與左右
- 每一次踐踏落在哪裡、每一刀往哪個方向掃 → 重擊的聲像、刀聲在左右之間掃過
- 網格每一列印出的那一拍 → 乾而一致的戳印聲
- 第 10 段每一對輪廓 → 左右各一個音：友與仇是五度，人與獸是三全音，愛者與不愛者是同一個音、其中一個微微走音
- 第 12 段每一個字被吹走的時刻與位置 → 一片紙的窸窣，從右到左

3:01 驟停時連殘響一起切掉，直到「去罷」才回來；最後 3 秒完全無聲。

## 準備

- Python 3、`numpy`、`scipy`、`Pillow`、`pycairo`、`fonttools`、`brotli`，以及 PATH 上的 `ffmpeg`。
- 字體：執行 `tools/fetch_fonts.sh`。

## 使用

```bash
tools/fetch_fonts.sh                            # 第一次：取得字體
python3 render.py --still 66.5 123.9            # 單張檢查 → out/still_*.png
python3 render.py --sound                       # 只生成聲音 → out/sound.wav
python3 render.py --range 61.5:71.5 --name s4   # 片段（含聲音）→ out/s4.mp4
python3 render.py --full                        # 全片 → out/yecao_tici.mp4
python3 make_storyboard.py                      # 依剪輯重新產生 STORYBOARD.md
```

多核心並行：影格範圍切成數段，各段由場景起點重播模擬（只模擬、不繪製）到段首再開始渲染，結果與單線程一致。

## 脈搏

全片的拍子由 `[pulse]` 產生（66.26 BPM，錨點在 2:03.32 熔岩噴出那一拍）。踐踏與刪刈、網格印出、作證時分界線的每一次重切、「大笑」「歌唱」的起伏，都落在這個網格上；聲音從同一份時間軸生成。
