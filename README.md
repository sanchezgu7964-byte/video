# Mateo XXV, 30 — procedural montage (v2)

Everything in this film is generated by code: images with numpy + Pillow, sound
with numpy, encoding with ffmpeg. There are no external images or audio. The only
outside files are system fonts, used for contact-sheet labels and placeholder frames.
All randomness comes from `meta.seed` in `timeline.json`, so the same json always
renders the same film, frame for frame.

**Status:** v2. There are 33 segments and the film runs about 154 s
(3,700 frames). Segments 1–13 are unchanged from v1. v1's temporary ending was
removed, and segments 14–33 replace it. v1's files are kept in `out/v1/`.

## Requirements
Python 3 with `numpy` and `Pillow`, plus `ffmpeg` on the PATH. No scipy, opencv or moviepy.

## Rendering
```bash
python3 render_segment.py --list                      # timeline + which segments are written
python3 render_segment.py -s rail_yard                # one segment, full res, with its sound
python3 render_segment.py -s 1 2                      # by number, several at once
python3 render_segment.py -s viaduct --preview        # half resolution (about 3x faster)
python3 render_segment.py -s viaduct --still 0 3 5.9  # PNG stills at those seconds
python3 render_segment.py -s rail_yard --audio-only   # redo only the sound, keep the video

python3 render_full.py                                # whole film → out/montage_v2.mp4 (meta.output_name)
python3 render_full.py --upto rail_yard               # only segments 1..2, joined
python3 render_full.py --preview
python3 render_full.py --audio-only                   # new soundtrack only
```
Rendering runs at about 2.5–3 frames per second on 4 cores. Segment preview
mp4s are saved separately from the full film, so trying out one segment never
overwrites the full render.

## Changing the edit (timeline.json only)

### Duration and shot count
Each entry in `segments` takes one of these forms:
```jsonc
{"name": "viaduct", "duration": 6.0}                       // one shot, 6 s
{"name": "stars", "shots": 3, "shot_durations": 1.0}       // 3 shots, 1 s each
{"name": "cards", "shots": 3, "shot_durations": [2, 2, 2]} // explicit list
{"name": "libraries", "shots": 10,
 "shot_durations": {"from": 0.4, "to": 0.1, "curve": "linear"}}  // accelerating
```
`curve` can be `linear`, `ease_in` (stays slow, then speeds up sharply), `ease_out`
or `exponential`. If you add `"duration"` next to a `from/to` curve, the curve is
stretched to fit that total.

### Locking cuts to the beat
`music.bpm` (90) and `music.anchor_segment` (`stars`) set the beat grid. Any segment
with `"snap": "1/16"` (or `"1/32"`, `"1/4"`, …) has its cut points moved to that
grid, so cuts land on the music. That's why 0.6 s bread shots come out as
0.583/0.667 s. Remove `snap` to get exact durations instead. At 90 bpm the grid
values come out as whole frames: 1/4 = 16 frames, 1/16 = 4, 1/32 = 2.

Run `python3 render_segment.py --list` after editing to check the actual frame-exact
durations.

### Colours and look
- `look` (global): `bw_tint` is the cold cast on black-and-white frames
  (`[1,1,1]` = neutral). Also `grain`, `grain_size`, `vignette`, `flicker`, `dust`
  (0 turns an effect off).
- Per segment: `"look": "bw"` or `"color"`. Add `"look_override": {"grain": 0.02}`
  to change the film treatment for one segment only.
- `palette` holds hex colours for the colour segments, for example the sky of 最後審判
  or the crust and crumb of 麵包.
- `params` holds the per-segment drawing knobs:

| segment | params |
|---|---|
| viaduct | `drift` (camera movement), `fog_distance`, `fog_level`, `shadow` |
| rail_yard | `train_cars`, `train_speed` (m/s), `train_track`, `switch_x`, `glint`, `lamp_pool`, `camera_follow` |
| smoke | `stars`, `particles`, `rise_speed`, `density` (how much the smoke covers) |
| last_judgment | `color_in_start` / `color_in_end` (0..1 of the segment); sky colours in `palette` |
| blackout | `flashes`, `flash_length` (s), `opacity`, `sources` (which segments flash up) |
| sound | `rings`, `brightness` |
| chess | `morph_seconds` (how long the table → board transformation takes) |
| basement | `glow`, `speed` |
| body | `steps_per_second` (also times the footsteps), `sheen` (floor reflection) |
| nail | `growth` (how far the lunula arc extends) |
| shadow | `detach_start`, `fade_end` (0..1 of the segment) |
| mirrors | `mirrors_per_shot` (list), `depth` (levels of recursion), `wobble` |
| music_slide | `semitones` (how far the music slides down) |
| frontier | `horses` |
| charge | shot compositions cycle through `KINDS` in `s22_charge.py`; colours in `palette` |
| days | `people` |
| dream_treasure | `glow` |
| chance | `freeze_at` (s): the frame freezes here |
| memory | `distance_from` / `distance_to` (m), `fov_from` (°): the dolly zoom |

### Sound
All sound is synthesised in `montage/audio.py` (segments 1–13) and `montage/audio2.py` (14–33). Each layer has a block under
`audio` in timeline.json:

| block | where | what |
|---|---|---|
| `train` | 01–03 | wheel clacks (da-dum per beat), metallic hum, rumble, flange squeal, distant whistle |
| `rise` | 04 | a tone rising two octaves as the colour arrives; cut dead at the blackout |
| `drone` | 05–06 | low drone + a deep bell ping on every ripple of 06 |
| `minimal` | 07–12 | three mallet voices on the beat grid, a pad under cards/chess, bass, a tick on every cut, the train clack as a heartbeat |
| `basement` | 13 | room tone and two distant drips, nearly silent |
| `quiet` | 14–16 | room tone and footsteps (synced to 身體's steps) |
| `mirror_music` | 17–18 | the mallet patterns return; voices join as the mirrors multiply (`from_shot`), then everything slides down `music_slide.params.semitones` |
| `warm` | 19–23 | warm chords per segment (`chords`); dense low drum pulses in 22 |
| `long_tones` | 24–28 | slow transparent tones per segment; dice clicks in 27; in 28 two tones pulled apart and a filter opening, following the dolly zoom |
| `flashback` | 29 | grains of everything heard before, one per shot |
| `low_hold` | 30 | one very low held tone; `mute_zone` silences everything else here |
| `sacred` | 31 | slow open fifths and octaves with a long reverb |
| `train_last` | 32–33 | only the train, fading out; `silence_from` makes the last ~2 s pure silence |

Layers that change level over time take an `envelope`: a list of
`[segment, "start"|"end", offset_seconds, level]` points, so they follow the edit.
In `minimal`, `voices` sets each voice's note pattern (`"-"` is a rest) and its
`division` (8 = eighth notes). `sections` sets which voices play in which segment
and how loud, and `"every": 2` thins them to half density.
Everything ends in a soft limiter at `audio.ceiling_db` (−1 dBFS), so nothing
clips.

To change only the sound, run `render_segment.py -s <name> --audio-only` for one
segment or `render_full.py --audio-only` for the whole film. Either one swaps the
new mix into the existing mp4 in a few seconds, without re-rendering any video.

### Subtitles
Edit the `subtitles` lists in timeline.json. Times are relative to the start of the
segment, so they move with the edit. Then run `python3 make_subtitles.py`, which
`render_full.py` also runs. You can also edit `subtitles.srt` directly, but it is
overwritten on the next full render.

### File size
The grain makes files large: about 37 MB for 6–8 s at the default `meta.crf: 20`.
Use 23 for smaller review copies, or 17 for a master. `"x264_tune": "grain"`
keeps the grain sharper but makes the file roughly twice as big.

## Adding or rewriting a segment
Create `montage/segments/sNN_name.py`:
```python
from . import segment

@segment("name_in_timeline")
def render(ctx):
    # ctx.t / ctx.u        time in segment (s) / progress 0..1
    # ctx.shot, ctx.shot_t, ctx.shot_u   current shot
    # ctx.params, ctx.palette            from timeline.json
    # ctx.rng()            per-frame RNG; ctx.seed(...) for stable seeds
    # ctx.canvas()         antialiased vector canvas; ctx.scale = H/1080
    # ctx.other("viaduct", f)  context for rendering another segment's frame
    return image   # HxW (black & white) or HxWx3 (colour), floats 0..1
```
The module is picked up automatically. Grain, vignette and dust are applied afterwards.
